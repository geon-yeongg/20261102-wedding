모바일 원페이지 웹 청첩장

1. index.html을 브라우저에서 열면 미리 볼 수 있습니다.
2. index.html: 이름, 날짜, 장소, 초대 문구, 계좌 정보, 지도 주소를 변경하세요.
3. style.css: 색상, 여백, 글자 크기 등 디자인을 변경하세요.
4. script.js: 갤러리 팝업과 계좌번호 복사 기능을 관리합니다.
5. assets/: 참고 시안에서 잘라낸 실제 JPG 이미지 파일입니다. 원본 고해상도 웨딩 사진으로 교체하면 더 선명합니다.
6. 지도는 실제 예식장이 지정되지 않아 서울 강남 테헤란로를 검색하는 예시 구글 지도 링크입니다. 약도도 실제 지도 스크린샷이 아닌 스타일링된 안내 이미지입니다.
7. 클립보드 복사는 HTTPS 또는 localhost에서 가장 안정적으로 동작합니다.
